材料阻抗 Smith 圆图 Web UI 使用说明

离线网页工具：读取电磁参数数据，计算材料本征阻抗或有限厚度吸波层输入阻抗，并绘制 Smith 圆图。

## 打开

1. 完整解压 ZIP 文件。
2. 双击 "index.html"，使用 Edge、Chrome 或 Firefox 打开。
3. 将文件拖入页面或浏览文件选中即可。

无需安装 Python，无需联网，也无需运行命令行。实验数据仅在本地处理。

##支持的数据以及格式

Excel：".xlsx"、".xlsm"、".xls"
文本：".csv"、".txt"、".tsv"

工具会自动扫描文件，忽略仪器信息、说明行、空行和表头前内容。
列名应能对应 "frequency"、"e'"、"e''"、"u'"、"u''"，列顺序不限。
"data-template.csv" 可作为新数据文件的列名模板。

默认复数约定：

εr = ε' - jε''
μr = μ' - jμ''

## 计算模式

**材料本征阻抗**："z = sqrt(μr/εr)"。
**有限厚度吸波层（一般采用）**：自由空间正入射、单层均匀介质、理想金属背板。输入厚度后，计算归一化输入阻抗、反射系数和反射损耗。

## 导出

csv：逗号分隔，包含原始损耗列、有符号复数虚部、归一化阻抗、反射系数和反射损耗；厚度模式额外记录厚度。
csv：制表符分隔，可直接导入 Origin。
SVG：当前 Smith 图矢量文件。
PNG：当前 Smith 图高分辨率图片。

## Origin 数据后处理

1. 将导出的txt或csv文件拖入 Origin。
2. 点击上方“绘图”——“专业图”——“史密斯图”。
3. X 列勾选 ”z_real“，Y 列勾选 ”z_imag“。
4. 点击“确定”，再按需调整格式。
